01 · Bối cảnh

Component sinh ra theo từng feature, không theo một hệ thống chung

  • Công ty chưa có người chịu trách nhiệm chính về design system.
  • Feature mới ra liên tục, component được thêm vào tùy ý theo từng feature.
  • Dev lấy component ngay trong file màn hình feature, không vào design system trên Figma.
  • Dev phàn nàn: tên component không thống nhất nên rất khó tìm và khó quản lý.

04 · Bài học

Kỹ năng mới của designer: biết làm việc cùng AI.

AI rà soát nhanh, tôi định hướng rõ. Hai bên cùng làm thì 2 tuần là đủ để quy hoạch lại cả thư viện.

  1. Trợ lý đắc lực
    cho việc lớn.

    Rà hàng trăm component và icon nhanh hơn rất nhiều so với làm tay, tiết kiệm đáng kể thời gian và công sức.

  2. Nền tảng vững
    để dùng AI đúng.

    AI đưa ra đề xuất. Kinh nghiệm giúp chọn gộp hay giữ, variant nào hợp với app, chính xác và sát thực tế.

  3. Thư viện sống
    cần kênh cập nhật.

    Feature mở rộng liên tục thì cần tab Cập nhật gần đây để dev theo kịp.

Bước tiếp theo
  • Hoàn thiện design system mới, cập nhật số liệu “sau”.
  • Tìm hiểu cách đưa thư viện từ Claude Design sang Claude Code rồi lên GitHub, để dev duyệt thay đổi qua Pull Request và code tự cập nhật.
